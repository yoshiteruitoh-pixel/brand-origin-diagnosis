# ブランド起点診断

授業用のStreamlitアプリです。学生が「最近夢中になっているもの」を出発点に、自分がどこから価値を考え始める傾向があるかを診断します。

## サブタイトル

あなたはどこから価値を考え始める人ですか？

## 機能

- STEP1：最近夢中になっているものの入力
- STEP2：1問ずつ進む16問のブランド起点診断
- 現在の進捗表示
- カード型UIでの回答
- STEP3：自己起点・他者起点・社会起点・文化起点の点数表示
- 大きめのレーダーチャート表示
- 4つの起点スコアにもとづくタイプ判定
- 「あなたはどこから価値を考え始める人ですか？」に答える結果コメント表示
- STEP1の入力内容と診断結果を関連付けるコメント表示
- STEP4：納得した点、意外だった点、STEP1とのつながり、ブランド構想の振り返り入力
- CSVダウンロード

## タイプ判定

4つの起点スコアのうち、最高得点の軸に応じてタイプを表示します。

- 自己起点：クリエイター型
- 他者起点：コミュニティ型
- 社会起点：ソーシャル型
- 文化起点：ヘリテージ型

最高得点が同点の場合は、複数タイプを組み合わせた複合型として表示します。

## STEP1の入力項目

- 名前
- 学年
- 学籍番号
- 最近、時間を使っているもの
- 最近、お金を使っているもの
- 最近、つい調べてしまうもの
- その中で一番好きなもの
- なぜそれが好きなのですか？

名前、学年、学籍番号はCSV保存に使うため入力が必要です。診断開始には、これら3項目と「最近夢中になっているもの」に関する5項目の入力が必要です。

## 使用技術

- Python
- Streamlit
- pandas
- matplotlib

## セットアップ

```bash
pip install -r requirements.txt
```

## 起動方法

```bash
streamlit run app.py
```

ブラウザで表示されたURLを開くと、アプリを使用できます。

## 採点方法

各設問の選択肢は、次の起点に対応しています。

- A：自己起点
- B：他者起点
- C：社会起点
- D：文化起点

Q1〜Q16を1問ずつ表示し、回答すると次の質問へ進みます。16問の回答数を合計し、4つの起点ごとの点数として表示します。

## CSV保存項目

- 回答日時
- 名前
- 学年
- 学籍番号
- 最近、時間を使っているもの
- 最近、お金を使っているもの
- 最近、つい調べてしまうもの
- 一番好きなもの
- 好きな理由
- 自己起点
- 他者起点
- 社会起点
- 文化起点
- 判定タイプ
- タイプ説明
- STEP1とのつながりコメント
- 振り返り_納得した点
- 振り返り_意外だった点
- 振り返り_STEP1とのつながり
- 振り返り_ブランド構想
- Q1〜Q16の回答
